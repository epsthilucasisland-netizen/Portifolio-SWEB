Este repositório apresenta o **Portfólio SWEB**, desenvolvido pelo grupo formado por **Lucas Souza e Thiago Maia** durante nossa trajetória acadêmica na área de Desenvolvimento de Sistemas.

## 🚀 Como Executar os Projetos

Cada projeto presente no Portfólio SWEB pode possuir requisitos e formas de execução diferentes.

Projetos desenvolvidos em **PHP** podem necessitar de um servidor local, como XAMPP ou WAMP, além da configuração do banco de dados quando necessário.

Projetos desenvolvidos em **Java** podem ser executados utilizando uma IDE compatível, como IntelliJ IDEA, Eclipse ou Apache NetBeans.

Projetos desenvolvidos com **HTML, CSS e JavaScript** podem ser executados diretamente em um navegador.

As instruções específicas de cada projeto poderão ser encontradas dentro de suas respectivas pastas.
